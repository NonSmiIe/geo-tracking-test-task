The supplied assignment asks for a FastAPI service that receives moving-device positions, checks user-private circular geozones in PostGIS, and streams locations and alerts to every active session of the relevant user. The principal design risks are spatial-query cost, bounded admission, slow WebSocket consumers, and preserving every report needed for alert evaluation.

Source: the assignment (TestTask.docx). Implementation plan: [implementation plan](plan-2026-10-01.md).

## Required outcomes

- Python 3.10+, FastAPI, PostgreSQL with PostGIS, SQLAlchemy, Docker Compose.
- HTTP or WebSocket ingestion of device ID, latitude, longitude and timestamp.
- REST create, read, update and delete for circles with a centre and radius in metres.
- WebSocket location updates and notifications when a device reports within a user's active zone.
- Basic user identification; mock authentication is explicitly acceptable.
- Multiple simultaneous sessions per user receive updates; zones remain private to their owner.
- Async generator simulates 10,000 unique devices reporting every few seconds with moving coordinates.
- Git repository, Compose environment, generator and README covering execution and architecture.
- Evaluation explicitly includes pooling, backpressure, async correctness, efficient PostGIS functions, code quality, core spatial tests and secure container configuration.

## Interpretation and unspecified dimensions

The detailed alert requirement supports notifications on each inside report. Entry-only semantics would suppress required notifications. The assignment does not define device ownership, dashboard count, total geozone count, overlapping-zone density, acceptable latency, offline replay, full history or horizontal deployment. The plan chooses a shared demonstration fleet and user-private zones and alerts, and makes those choices visible.

10,000 devices at five-second intervals produce 2,000 reports per second; two-second intervals produce 5,000. Device count does not prescribe transport connection count. Dashboard count multiplies outbound work, and dense overlapping zones multiply alert work. A credible benchmark must name all of these dimensions and the test machine.

## Verified technical references

[PostGIS ST_DWithin](https://postgis.net/docs/ST_DWithin.html) documents geography distance in metres and index-aware distance predicates. Its variable-range examples also show why exact query shape matters; an index declaration alone is insufficient evidence.

[SQLAlchemy async sessions](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html) and [pooling](https://docs.sqlalchemy.org/en/20/core/pooling.html) are the primary references for session ownership and bounded asynchronous database access.

[FastAPI WebSockets](https://fastapi.tiangolo.com/advanced/websockets/) explicitly limits its example in-memory connection manager to a single process. The implementation must enforce that deployment scope or adopt cross-process routing.
